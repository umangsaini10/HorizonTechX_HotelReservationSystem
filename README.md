
# Hotel Reservation System – Horizon TechX Internship

## About the Project
The Hotel Reservation System is a Java-based application developed as part of the Horizon TechX Java Programming Internship.

The application provides a simple platform to manage hotel room reservations. Users can view available rooms, select room categories, make reservations, cancel bookings, and view booking details.

## Features
- View available hotel rooms.
- Search rooms by category.
- Support Standard, Deluxe, and Suite rooms.
- Book hotel rooms.
- Cancel existing reservations.
- Simulate the payment process.
- View booking details.
- Maintain reservation records.

## How to Run
1. Clone or download this repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Locate the main Java class.
4. Run the application.
5. Follow the console instructions to manage reservations.
